# 📺 Video Gallery Website (HTML & CSS)

A responsive **Video Gallery Web Page** created using **pure HTML and CSS only**.
This project displays videos in a modern TV-style layout with thumbnails, preview section, and a clean content arrangement similar to a streaming platform.

The goal of this project is to practice **layout design, flexbox, hover effects, image overlays, and responsive UI development** without using JavaScript.

---

## 🚀 Live Demo

Live Demo: https://videogalleryprateek.netlify.app/

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Google Fonts
